Install

About ten minutes. One container, one phone line.

git clone https://github.com/plow-pbc/plow-agents.git
export PATH="$PWD/plow-agents/bin:$PATH"
plow-agents login --new-line
git clone https://github.com/MAUXII/gazette.git
cd gazette && plow-agents mint ln_xxx
docker compose up --build -d

Text hi to your new number. City, topics, delivery time in one reply.
